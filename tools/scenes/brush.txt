# The Brush panel. Its list is many times taller than the window, so every press here also
# exercises the harness scrolling a control into view.
#
# Sliders are named by id rather than by label on purpose: six of this panel's labels -- Size,
# Flow, Hardness, Spacing, Roundness, Angle -- belong to two controls each, the slider and the
# picker that says what drives it. A person tells them apart by where they are; a script cannot,
# and must say which it means.
tab Brush
expect brush.size 8.000
expect brush.hardness 0.500
expect brush.spacing 0.250
expect brush.roundness 1.000
expect brush-tip round

# The five shape sliders.
slide brush:1048577 0.75
about brush.size 75 30
slide brush:1048578 0.9
about brush.hardness 0.9
slide brush:1048579 0.5
about brush.spacing 0.5
slide brush:1048580 0.4
about brush.roundness 0.4
slide brush:1048581 0.25
about brush.angle 0.25
shot brush-shape

# Stabilization, flow and opacity.
slide brush:1048582 0.5
about brush.stabilization 100 25
slide brush:1048583 0.5
about brush.flow 0.5
slide brush:1048584 0.6
about brush.opacity 0.6
shot brush-flow

# What drives each parameter: a Pick whose list is the five modulation sources.
expect response.size Pressure	2
press brush:1048832
shot brush-source-open
press Velocity
expect response.size Velocity	2

# And back to defaults, which must move every one of them home.
press Reset to defaults
expect brush.size 8.000
expect brush.hardness 0.500
expect brush.spacing 0.250
expect brush.roundness 1.000
expect brush.angle 0.000
expect brush.flow 1.000
expect brush.opacity 1.000
expect response.size Pressure	2
shot brush-reset

# The curve editor under each picker: a press on empty track adds a point, a right-click on a
# point takes it away. 1049088 is Size's curve (FIRST_CURVE + 0).
expect response.size Pressure	2
press brush:1049088
expect response.size Pressure	3
shot brush-curve
rpress brush:1049088
expect response.size Pressure	2

# Naming and saving a brush. The letters of a name are letters, not shortcuts: typing "beeper"
# here used to select the eraser, step the size twice and refit the view, because every
# unmodified key was read as a tool key as well.
tab Brush
expect presets 
expect tool Brush
press brush:1048585
type beeper
expect tool Brush
expect brush.size 8.000
key enter
slide brush:1048577 0.6
press Save brush
expect presets beeper
shot brush-saved

# A saved brush comes back when its row is pressed, whatever the sliders have been moved to since.
slide brush:1048577 0.2
press Reset to defaults
expect brush.size 8.000
press brush:0
about brush.size 30 25
shot brush-applied

# And Forget takes it away again.
press Forget beeper
expect presets 
shot brush-forgotten

# **All six response pickers and all six curves.** Only the first of each had ever been touched, so
# a picker wired to the wrong response, or a curve editor pointed at its neighbour, would have gone
# unnoticed five times over. Each one is given a different source, and then all six are read back
# at once -- so two of them crossed would show as two wrong answers rather than none.
tab Brush
press Reset to defaults

press brush:1048832
press Tilt
expect response.size Tilt	2
press brush:1048833
press Velocity
expect response.flow Velocity	2
press brush:1048834
press Direction
expect response.hardness Direction	2
press brush:1048835
press Random
expect response.spacing Random	2
press brush:1048836
press Pressure
expect response.roundness Pressure	2
press brush:1048837
press Tilt
expect response.angle Tilt	2
shot brush-sources

# And the curve under each picker: a press on empty track adds a point to that response and to no
# other. Adding one to each in turn and reading all six back is the check that they are six
# editors and not one drawn six times.
press brush:1049088
expect response.size Tilt	3
press brush:1049089
expect response.flow Velocity	3
press brush:1049090
expect response.hardness Direction	3
press brush:1049091
expect response.spacing Random	3
press brush:1049092
expect response.roundness Pressure	3
press brush:1049093
expect response.angle Tilt	3
shot brush-curves

# Right-clicking a point takes it away again, from the same curve it was added to.
rpress brush:1049088
expect response.size Tilt	2
rpress brush:1049089
expect response.flow Velocity	2
rpress brush:1049090
expect response.hardness Direction	2
rpress brush:1049091
expect response.spacing Random	2
rpress brush:1049092
expect response.roundness Pressure	2
rpress brush:1049093
expect response.angle Tilt	2

# The edge profile is a seventh curve, and not a response: its axis is distance within the dab
# rather than an input, which is why nothing drives it. It is only reachable while the tip is a
# procedural one, which it is until a bitmap is loaded.
press brush:1048590
shot brush-edge
rpress brush:1048590
press Reset to defaults
expect brush-tip round

# **Editing inside a field, rather than replacing it.** Every other `type` in this suite lands in a
# field that arrives selected, so the first keystroke replaces the lot and the caret is never
# actually moved. Here the caret is walked about and the text mended in place, which is the only
# way to find out whether the field is a text field or a box that accepts one word.
press brush:1048585
type inkr
key left
type e
key home
type f
key end
type s
key enter
press Save brush
expect presets finkers

# **And the size reaches the dab.** Every slider here is asserted as a number and none of them as
# ink, which proves the panel wrote to the brush and says nothing about whether the brush uses it.
# Two strokes down the same line at two sizes: the wide one covers a box the narrow one misses.
# This matters more than it looks -- Windows Ink gives an injected pointer no pressure, so nothing
# else in this suite shows that the shape of a dab depends on anything at all.
press Reset to defaults
expect brush.size 8.000
drag 700 450 700 850
ink 660 600 690 700 0
key ctrl+z
slide brush:1048577 0.85
about brush.size 75 15
drag 700 450 700 850
ink 660 600 690 700 20
shot brush-wide
key ctrl+z
press Reset to defaults

# **Saving a brush with no name is refused**, out loud on stderr and silently on screen. The
# refusal branch had never been taken because every scenario named the brush first.
press Reset to defaults
press Forget finkers
expect presets
# The field still holds the last name that was typed into it, so it has to be emptied first --
# otherwise this saves that name again and proves nothing.
press brush:1048585
key ctrl+a
key delete
key enter
press Save brush
expect presets
