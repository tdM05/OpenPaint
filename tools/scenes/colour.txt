# The Colour panel: the wheel, the palette, and the three wheel shapes.
tab Colour
expect palette 0
expect colour 141418

# Dragging inside the wheel changes the paint colour. The wheel is control 0 in this panel, and
# what is asserted is the colour afterwards -- a wheel that answered a constant, or answered
# nothing, would have passed on a screenshot.
slide colour:0 0.7
expect colour 040480
shot colour-picked

# Keeping a colour puts a chip in the document's palette. A second colour makes a second chip --
# the same colour twice does not, and that refusal is deliberate (Document::add_to_palette).
press Keep this colour
expect palette 1
press Keep this colour
expect palette 1
slide colour:0 0.3
press Keep this colour
expect palette 2
shot colour-kept

# The swatch grid is control 16: left-click a chip to paint with it, right-click to forget it.
# The chips are row-sized squares from the left of a box the full width of the panel, so a press
# has to say which chip it means -- the middle of the box is empty space. Pressing one paints with
# it: the colour has to become that chip's, which is the first one kept above.
slide colour:0 0.9
pressat colour:16 16 16
expect colour 040480
shot colour-used
rpressat colour:16 16 16
expect palette 1
shot colour-forgotten

# The three wheel shapes. Nothing in the document changes -- it is a setting of the shell -- so
# until the application would say which shape was on, three screenshots were the whole of the
# evidence and a button wired to the wrong shape would have passed.
expect wheel-shape Ring
press Triangle
expect wheel-shape Triangle
shot colour-triangle
press Square
expect wheel-shape Square
shot colour-square
press Ring
expect wheel-shape Ring
shot colour-ring
